Cómo practicar HTML y CSS

Empieza aquí si todavía no conoces etiquetas. HTML describe el contenido; CSS cambia su presentación. En cada módulo, localiza la etiqueta o el selector del ejemplo antes de editar.

  1. Lee la misión y conserva la estructura que ya te damos.
  2. Cambia una cosa y pulsa Ver resultado para ver su efecto en el panel aislado.
  3. Compara lo que ves con las tres comprobaciones. Las comprobaciones buscan patrones básicos: no sustituyen revisar visualmente tu página.

La vista previa no ejecuta scripts y solo muestra imágenes incrustadas: una dirección externa no se descarga, para que nada de lo que escribas salga a la red. Es blanca para representar tu página independientemente del tema del sitio. Al estudiar hover, recuerda que móviles y teclado necesitan una alternativa como :focus-visible.
