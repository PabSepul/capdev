Antes de escribir una consulta

Primero, entiende dónde viven los datos.

Imagina que administras una academia. Quieres saber qué cursos ofrece, cuánto duran y quién estudia en cada uno. SQL es el lenguaje que usarás para hacer esas preguntas a una base de datos.

01

Base de datos

Es una colección organizada de información. Nuestra academia tiene una base de práctica con dos tablas: cursos y estudiantes.

02

Tabla, fila y columna

Una tabla se parece a una hoja de cálculo: cada fila es un registro (un curso) y cada columna es una característica (nombre, nivel o duración).

03

Consulta y resultado

Una consulta es una pregunta escrita en SQL. SELECT devuelve una tabla de resultados; no cambia los datos originales. Puedes consultar cuantas veces necesites.

Lee esta fila como una frase

id: 1 · nombre: Python · duracion: 12 significa: «El curso identificado con el número 1 se llama Python y dura 12 horas». El identificador no es su duración ni su posición en un ranking.

Tu base de práctica

Los datos no son una caja negra.

Estos datos son ficticios y están incluidos en el navegador. Revisa los encabezados antes de consultar: usa exactamente sus nombres, por ejemplo duracion sin tilde. Ningún ejercicio cambia estas tablas.

           Vuelve aquí cuando lo necesites
          
      
          Una guía para pensar la consulta.
          
      
          Antes de escribir, responde tres preguntas: ¿de qué tabla vienen los datos?, ¿qué filas necesito?, ¿qué quiero mostrar o calcular? No intentes memorizar todo de una vez.
          
      
          
        
          Cómo se escribe
          SELECT columnas_o_resumen
FROM tabla
WHERE condicion
GROUP BY columna
ORDER BY columna ASC
LIMIT cantidad;
          Solo SELECT y FROM son necesarios en los ejercicios de esta ruta. Agrega las otras cláusulas cuando la pregunta las necesite; los nombres de esta plantilla son lugares para completar, no una consulta lista para ejecutar.
          
        
          Cómo entender lo que ocurre
          1. FROM / JOIN: busca y relaciona los datos.
          2. WHERE: deja pasar las filas que cumplen.
          3. GROUP BY y funciones: forma grupos y calcula sus resúmenes, si los pediste.
          4. SELECT / DISTINCT: elige qué mostrar y elimina repeticiones si corresponde.
          5. ORDER BY / LIMIT: ordena y recorta el resultado.
          Es un modelo mental para estas consultas, no una descripción del algoritmo interno de todas las bases de datos.
          
      
          
      
          Diccionario de bolsillo: comandos y operadores
          
        
          SELECT / FROM
          Qué datos mostrar / de dónde obtenerlos.
          WHERE
          Qué condición debe cumplir una fila.
          = · > · >= · < · <= · <>
          Igual, mayor, mayor o igual, menor, menor o igual y distinto.
          AND / OR
          Ambas condiciones / al menos una condición.
          LIKE / BETWEEN / IN
          Coincidir con un patrón / estar dentro de un intervalo / pertenecer a una lista.
          COUNT / SUM / AVG / MIN / MAX
          Contar filas o valores, sumar, promediar, buscar el mínimo y el máximo.
          AS
          Dar un alias a una columna o tabla dentro de la consulta.
          JOIN ... ON
          Unir tablas según una relación entre sus columnas.
          
      
          
      
          Si aparece un error: revisa en este orden
          1. Comprueba el nombre de la tabla: cursos o estudiantes.
          2. Compara cada columna con el diccionario. duracion no lleva tilde.
          3. Separa columnas con comas y escribe los textos entre comillas simples.
          4. Respeta el orden de las cláusulas; el punto y coma va al final.
          5. Si unes tablas, aclara qué nombre pides: e.nombre o c.nombre.
          Si la consulta devuelve cero filas sin error, revisa el filtro: quizá ningún registro cumple la condición.
          
      
          Qué puedes practicar aquí y qué queda para después
          Este laboratorio interpreta un subconjunto de SQL sobre datos ficticios en memoria. Acepta SELECT, DISTINCT, WHERE, comparaciones, AND/OR/NOT, LIKE, IN, BETWEEN, agrupaciones, funciones de resumen, ORDER BY, LIMIT y un JOIN entre dos tablas.
          No es una base de datos completa: aquí no ejecutamos INSERT, UPDATE, DELETE, CREATE TABLE, HAVING, subconsultas ni LEFT JOIN. Los cambios de datos, valores NULL y otras uniones quedan para una siguiente etapa. AVG se presenta redondeado a dos decimales en este motor educativo.
